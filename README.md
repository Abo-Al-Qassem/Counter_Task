# Counter_Task

This Is Counter Task Using HTML, CSS And JS

## Features

- Increase the counter.
- Decrease the counter.
- Reset the counter.
- Counter color changes:
  - Green for positive numbers.
  - Red for negative numbers.
  - Black for zero.
- Responsive design for mobile devices.
